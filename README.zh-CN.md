# Send to Kindle

[English](README.md) | [简体中文](README.zh-CN.md)

一款轻量的 Windows 电子书投递小工具：把电脑里的书一键转换成 Kindle 认识的格式，自动发到你的 Kindle 书库——不插数据线，不用装 Calibre，不用手动写邮件。

## 它解决什么问题

把书放进 Kindle，通常很折腾：找软件转格式、翻出 Kindle 邮箱地址、开邮件客户端、加附件、记规则……一本书重复一遍，下次再来一遍。

用这个工具，只需要三步：**选文件 → 点发送**，剩下的它全包了：

- 不认识的格式（AZW、MOBI、DOCX、Markdown、PDF、TXT、HTML 等）自动转成 EPUB 再发
- 本来就是 EPUB 的文件直接发，不重复处理
- 每本书单独一封邮件，附件发送，邮件标题就是书名
- 邮箱配置保存在本地，下次打开不用重填

## 快速开始

### 1. 安装并启动

需要 Python 3.11 或更高版本：

```bash
pip install -r requirements.txt
python main.py
```

### 2. 获取邮箱授权码

大多数邮箱**不允许用登录密码直接发信**，需要先在邮箱官网生成一个专用的「授权码」。步骤大同小异：

1. 用浏览器登录你的邮箱网页版
2. 进入「设置」，找到「**账户**」或「**POP3 / IMAP / SMTP**」相关选项
3. 开启「**SMTP 服务**」（可能需要短信验证）
4. 按提示**生成授权码**——有的邮箱叫「客户端授权密码」或「应用专用密码」
5. 复制授权码，填进本工具配置里的「密码」一栏（**不是**登录密码）

常见邮箱速查：

| 邮箱 | SMTP 服务器 | 端口 / 加密 | 去哪里拿授权码 |
|---|---|---|---|
| QQ 邮箱 | `smtp.qq.com` | 465 / SSL | 设置 → 账户 → 开启 SMTP → 生成授权码 |
| 163 / 126 / yeah | `smtp.163.com`（yeah 用 `smtp.yeah.net`） | 465 / SSL | 设置 → POP3/SMTP → 开启 → 客户端授权密码 |
| Gmail | `smtp.gmail.com` | 465 / SSL | 需先开启两步验证，再创建「应用专用密码」 |
| Outlook / Hotmail | `smtp.office365.com` | 587 / STARTTLS | Microsoft 账户 → 安全 → 应用密码 |

### 3. 填写配置

点击主界面的**配置**按钮，按上表填入服务器、端口、账号和授权码，再填**目标邮箱**（你的 Kindle 专属邮箱，格式类似 `xxx@kindle.com`），保存即可。配置会自动存在本地，长期有效。

> Kindle 专属邮箱在哪看？打开亚马逊官网 →「管理您的内容和设备」→「设置」→「个人文档设置」，里面列着你的 Kindle 收件邮箱。

### 4. 添加文件并发送

- 点**添加文件**，可一次多选，支持的格式都会亮出来
- 不要的条目选中后点**删除选中**
- 点**转换并发送**，状态栏会实时显示进度，完成后弹窗告诉你成功了几本、哪本失败以及原因

## 支持的格式

`epub`（直接发送）、`azw`、`azw3`、`mobi`、`prc`、`docx`、`html`、`txt`、`markdown`、`pdf`、`odt`、`fb2`、`rtf`

## 工作原理

```
选择文件 → 判断格式 → 转成 EPUB → 用你的邮箱发出 → Kindle 自动入库
           已是 EPUB    内置工具     每本书一封
           则跳过       自动完成     邮件
```

仓库里已经内置了 poppler 工具，供转换 PDF 时使用，**无需自行安装**任何额外环境。

## 注意事项

- **授权码别外传**：配置保存在本地 `config.json` 文件里（已被 git 忽略），仅供个人本机使用，请勿把该文件发给别人
- **附件别太大**：多数邮箱附件上限 25–50 MB，超大的 PDF 可能发送失败
- **单本失败不影响全局**：某本书转换或发送失败，其余的会继续处理，最后统一汇报失败原因
